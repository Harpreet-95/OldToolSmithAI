# Archived validation experiments

These scripts record earlier Phase 6 and Phase 7 engineering experiments.
They are retained for traceability but are not part of the supported setup,
demo, CI, or release-verification path. Some may require historical fixtures,
private data access, paid model calls, or configuration that no longer matches
the consolidated AI-first architecture.

Use the supported runners documented in the parent directory instead.

Some archived experiments may mention schema-only identifiers from the private
demonstration environment. They contain no business-row exports or credentials,
but they should be published only with the database owner's approval.
